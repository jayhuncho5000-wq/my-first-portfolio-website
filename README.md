Question 2: HTML Elements

1. Five HTML elements I found most challenging to implement

1. "<img>"

The "<img>" element was challenging because I had to correctly place the image file inside my project folder and use the correct file path in the "src" attribute. If the file path or filename was incorrect, the image would not appear on the website.

2. "<a>"

The "<a>" element required careful use because I needed to correctly use the "href" attribute to link to other sections of the page, external websites, and contact information.

3. "<form>"

The "<form>" element was challenging because it required several other elements such as "<label>", "<input>", "<textarea>", and "<button>". I also needed to understand how attributes such as "action", "method", "type", "name", and "placeholder" work.

4. "<table>"

The "<table>" element was challenging because I had to organise information correctly using "<table>", "<tr>", "<th>", and "<td>". I needed to ensure that rows and columns were properly structured.

5. "<blockquote>"

The "<blockquote>" element was challenging because I needed to understand when it should be used. I used it to display a quotation separately from the normal paragraph content.

2. How I used semantic HTML elements

I used semantic HTML elements to give my website a clear and meaningful structure.

- "<header>" was used for the top section of the website containing the main title and introductory information.
- "<nav>" was used to contain navigation links to different sections of the website.
- "<main>" was used to contain the main content of the website.
- "<section>" was used to divide the website into different areas such as About Me, Education, Skills, Projects, and Contact.
- "<article>" was used for independent pieces of content such as project information or detailed information.
- "<aside>" was used for additional or related information where applicable.
- "<footer>" was used for information at the bottom of the website, including copyright and other closing information.

Using semantic elements made the HTML easier to read, organise, and understand.

3. Which element was most useful for organising the layout?

The "<section>" element was the most useful for organising my layout.

I used "<section>" to separate different parts of my website into clear and meaningful groups. For example, I created separate sections for my biography, education, skills, interests, and contact information.

This made the website easier to navigate and made the HTML code more organised and readable.

Question 3: HTML Attributes

1. Three attributes essential for making the website functional

"href"

The "href" attribute was essential because it allowed me to create links. I used it in "<a>" elements to connect navigation links, external websites, and contact links.

"src"

The "src" attribute was important because it allowed me to display my image on the website. The attribute specifies the location of the image file.

"type"

The "type" attribute was important for form elements such as "<input>" and "<button>". It allowed me to specify the type of information expected, such as text, email, or submit buttons.

2. How I used "class" and "id" differently

The "id" attribute was used to give a unique name to a specific element. For example, different sections of the website could have IDs such as:

- "about"
- "education"
- "skills"
- "contact"

These IDs can be used to create navigation links that take the user directly to a specific section of the webpage.

The "class" attribute was used to identify multiple elements that belong to the same group or have a similar purpose. Unlike an ID, a class can be used more than once on different elements.

Therefore:

- An id is unique and identifies one specific element.
- A class can be shared by multiple elements.

3. Which attribute improved user experience the most?

The "alt" attribute improved user experience the most.

I used the "alt" attribute with images to provide a description of the image. This is useful if an image does not load correctly. It also improves accessibility because screen readers can read the alternative text to users who cannot see the image.

For example:

"alt="Portrait of Joy Kapiri""

Version control is important in web development because it allows developers to keep track of changes made to a project.
